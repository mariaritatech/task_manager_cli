# task_manager_cli

Aplicação de linha de comandos (CLI) desenvolvida em Node.js para criação, listagem e remoção de tarefas.

## 🚀 Tecnologias Utilizadas

- **Node.js**: Ambiente de execução JavaScript no servidor.
- **Inquirer.js**: Interface interativa para comandos no terminal.
- **File System (`fs`)**: Manipulação e persistência de dados em arquivos locais.

## ⚙️ Como Executar o Projeto

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/mariaritatech/task_manager_cli.git](https://github.com/mariaritatech/task_manager_cli.git)
   ```
